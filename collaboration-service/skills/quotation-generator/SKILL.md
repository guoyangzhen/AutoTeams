# 报价单生成

在沙箱工作目录内生成一份标准商务报价单（`quotation-{时间戳}.md`），并返回给用户确认。

## 步骤

1. 使用 `write` 工具在沙箱 cwd 写入报价单 Markdown 文件。
2. 报价单结构：
   - 报价单号（`Q{TIME}` 格式）
   - 客户信息（名称、联系人、日期）
   - 明细行（序号 / 产品名称 / 规格 / 数量 / 单价 / 小计）
   - 合计金额（含税率与币种）
   - 商务条款（有效期、付款方式、交付周期）
3. 金额计算通过 `bash` 校验合计，避免手算错误。
4. 向用户汇报报价单摘要与文件路径。

## 约束

- 所有文件写入必须在沙箱 cwd 内，不得越界。
- 未提供产品明细时，先向用户询问必要信息。
