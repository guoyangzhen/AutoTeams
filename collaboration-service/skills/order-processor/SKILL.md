# 订单处理

在沙箱工作目录内处理订单数据，生成订单处理报告。

## 步骤

1. 使用 `read` 工具读取沙箱 cwd 内的订单数据文件（CSV/JSON）。
2. 使用 `bash` 进行数据清洗、去重、状态归类。
3. 使用 `write` 工具产出订单处理报告（`order-report-{时间戳}.md`）。
4. 向用户汇总处理条数、异常项与建议。

## 约束

- 数据处理只在沙箱 cwd 内进行，不修改外部文件。
- 涉及金额、数量等数据时，用 `bash` 二次校验。
