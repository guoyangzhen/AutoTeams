# 产品知识检索

在沙箱工作目录内检索并整理产品相关资料，形成结构化知识摘要。

## 步骤

1. 使用 `ls` / `read` 工具浏览沙箱 cwd 内的知识库文件。
2. 定位与用户问题相关的文档，提取关键内容。
3. 使用 `write` 工具产出一份结构化摘要（`knowledge-summary-{时间戳}.md`）。
4. 向用户汇报核心结论与资料来源。

## 约束

- 只读取沙箱 cwd 内的文件，不访问外部目录。
- 回答优先引用资料原文，标注来源章节。
