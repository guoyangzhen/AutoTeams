## 1. V1 版本（优化前，已废止）

### 1.1 流程图

```
销售代表创建报价
       │
       ▼
销售总监审批 ──── 驳回 ──→ 退回销售代表修改
       │
       通过
       │
       ▼
发送给客户
```

### 1.2 V1 痛点

| 痛点 | 影响 |
|------|------|
| 无金额分级，所有报价都需销售总监审批 | 小额报价也占用总监时间，效率低 |
| 总监出差/休假时报价流程阻塞 | 客户等待时间长，丢单风险增加 |
| 无财务审核环节 | 价格合规性、税点计算无把关，存在出错风险 |
| 无审批时效要求 | 审批时长依赖个人，不可控 |

## 2. V2 版本（优化后，现行）

### 2.1 流程图

```
销售代表创建报价单
       │
       ▼
财务经理审核 ──── 修改意见 ──→ 退回销售代表修改
       │
       审核通过
       │
       ▼
按金额分级审批
       │
       ├── 报价金额 < 5 万元
       │       │
       │       ▼
       │   销售经理审批 ──── 驳回 ──→ 退回销售代表修改
       │       │
       │       通过
       │       │
       │       ▼
       │   发送给客户
       │
       ├── 报价金额 5-20 万元
       │       │
       │       ▼
       │   销售总监审批 ──── 驳回 ──→ 退回销售代表修改
       │       │
       │       通过
       │       │
       │       ▼
       │   发送给客户
       │
       └── 报价金额 > 20 万元
               │
               ▼
           CEO 审批 ──── 驳回 ──→ 退回销售代表修改
               │
               通过
               │
               ▼
           发送给客户
```

### 2.2 分级审批规则

| 报价金额区间 | 审批人 | 审批角色 | 审批时效 | 备注 |
|-------------|--------|---------|---------|------|
| < 5 万元 | 王浩然 | 销售经理 | 1 个工作日 | 含 5 万元 |
| 5-20 万元 | 李婉清 | 销售总监 | 2 个工作日 | 含 20 万元 |
| > 20 万元 | 张明远 | CEO | 3 个工作日 | 战略级报价 |

### 2.3 财务审核规则

| 审核项 | 审核要点 | 财务经理 |
|--------|---------|---------|
| 价格合规性 | 是否符合价格表标准报价/折扣规则 | 何德志（SL-2018-005） |
| 折扣合理性 | 折扣是否符合客户等级规则（见价格表第 8 节） | 何德志 |
| 付款条件 | 是否符合标准付款条件（30%预付+70%发货前） | 何德志 |
| 税点计算 | 13% 增值税计算是否正确 | 何德志 |
| 成本测算 | 毛利率是否 ≥ 30%（标准产品）/ ≥ 20%（定制产品） | 何德志 |

**财务审核时效**：收到报价单后 **1 个工作日内** 完成。

## 3. 审批流转规则

### 3.1 顺序

```
销售代表创建 → 财务经理审核 → 分级审批 → 发送客户
```

财务审核是 **必经环节**，先于分级审批。财务审核不通过的报价单不进入分级审批。

### 3.2 驳回处理

- 审批人驳回时必须填写驳回原因
- 销售代表收到驳回后 **2 个工作日内** 修改并重新提交
- 重新提交从财务审核环节重新开始

### 3.3 审批超时处理

- 超过审批时效未处理的，系统自动提醒审批人
- 超时 1 个工作日仍未处理的，自动升级至上一级审批人
- 超时 3 个工作日仍未处理的，系统通知 CEO

### 3.4 特殊报价

| 特殊场景 | 处理方式 |
|---------|---------|
| 低于大客户价的特殊折扣 | 必须由 CEO 直接审批，跳过分级 |
| 定制产品报价 | 需附加研发部成本测算，财务审核时一并审核 |
| 捆绑销售报价 | 按总价进入分级审批，明细列入报价单 |
| 加急报价 | 销售总监可申请加急通道，审批时效压缩至 4 小时 |

## 4. V1 与 V2 对比

| 维度 | V1（优化前） | V2（优化后） | 改进效果 |
|------|-------------|-------------|---------|
| 审批层级 | 统一总监审批 | 金额分级审批 | 小额报价效率提升 50%+ |
| 财务审核 | 无 | 必经环节 | 价格合规性保障 |
| 审批时效 | 无要求 | 1-3 工作日（按金额） | 流程可控 |
| 超时处理 | 无 | 自动提醒+升级 | 避免流程阻塞 |
| 总监负担 | 全部报价 | 仅 5-20 万报价 | 总监聚焦高价值审批 |
