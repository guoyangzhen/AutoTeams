## 3. 通信协议说明

### 3.1 下行协议支持矩阵

| 协议 | 接口 | 说明 |
|------|------|------|
| Modbus RTU | RS485 | 主/从模式，最大 32 设备/总线 |
| Modbus TCP | 以太网 | 主/从模式 |
| OPC UA | 以太网 | Client/Server，支持订阅 |
| MQTT | 以太网/4G | Broker/Client |
| LoRa | 无线 | 内置 SX1276，星型组网，最大 64 节点 |
| IEC 104 | 以太网 | 电力行业专用 |
| BACnet | 以太网/RS485 | 楼宇自控 |

### 3.2 上行协议支持矩阵

| 协议 | 说明 |
|------|------|
| MQTT | 主推，支持阿里云/华为云/腾讯云/自建 EMQX |
| HTTP/HTTPS | RESTful POST 上报 |
| TCP/UDP | 自定义协议透传 |
| OPC UA | 上行作为 Client |
| Modbus TCP | 上行作为从站 |
| 数据库 | MySQL/PostgreSQL/InfluxDB 直写 |

| 安装方式 | 说明 |

| DIN 导轨安装 | 标准 35mm DIN 导轨，控制柜内 |
| 壁挂安装 | 配壁挂支架（选配） |
| 桌面安装 | 配橡胶脚垫（选配） |

**安装注意事项**：
1. 控制柜内建议预留 100mm 上下散热空间
2. 双电源冗余接入时，主备电源应来自不同回路
3. 4G 天线建议外引至控制柜顶部，确保信号强度
4. RS485 总线末端建议加装 120Ω 终端电阻

## 8. 应用场景说明

### 场景一：智慧工厂设备联网

**客户痛点**：工厂设备涉及多种通信协议（Modbus、OPC UA、PLC 私有协议），数据孤岛严重。

**部署方案**：
- SL-GW500 接入 4 条 RS485 总线（每线 ≤ 32 设备）+ 2 路 OPC UA 设备
- 上行 4G + 以太网双链路，主备自动切换
- 边缘规则引擎实现设备联动（如温度告警触发空调）

**实施效果**：设备联网率从 30% 提升至 95%，数据完整率 99.5%。

### 场景二：智慧园区能源管理

**客户痛点**：园区水电气表分散，人工抄表滞后，无法分项计量。

**部署方案**：
- SL-GW500 接入园区电表（Modbus）+ 水表（MBus）+ 燃气表（LoRa）
- 上行 MQTT 接入园区能源管理平台
- 本地存储 30 天数据，断网不丢失

**实施效果**：实现分项计量，能耗下降 12%，年节省电费 80 万元。

### 场景三：分布式仓储环境监测集中采集

**客户痛点**：连锁仓储全国分布，环境数据需要集中管理。

**部署方案**：
- 每仓库部署 1 台 SL-GW500 + N 台 SL-T100
- 4G 上云至总部 SaaS 平台
- 配合 SL-CT800 实现冷机联动

**实施效果**：全国 50 仓数据集中可视化，异常响应时长下降 70%。
