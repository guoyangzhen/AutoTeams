## 3. 通信协议说明

### 3.1 Modbus RTU（默认）

| 项目 | 说明 |
|------|------|
| 物理层 | RS485，半双工 |
| 波特率 | 2400 / 4800 / 9600 / 19200 / 38400 bps（默认 9600） |
| 数据格式 | 8N1（默认）/ 8E1 / 8N2 |
| 站地址 | 1-247（默认 1） |
| 寄存器 | 温度：40001（INT16，0.01°C/LSB）<br>湿度：40002（UINT16，0.1%RH/LSB）<br>露点：40003（INT16，0.01°C/LSB）<br>设备状态：40004（UINT16） |

### 3.2 MQTT

| 项目 | 说明 |
|------|------|
| 传输层 | TCP/TLS |
| 端口 | 1883（TCP）/ 8883（TLS） |
| QoS | 0 / 1 / 2（默认 1） |
| 主题结构 | `smartlink/{device_id}/{channel}`<br>例：`smartlink/SL-T100-20260001/temp` |
| 数据格式 | JSON：`{"ts":1719600000,"temp":25.6,"humi":58.3,"dewp":16.5,"status":0}` |
| 上报周期 | 可配置 5s ~ 24h（默认 60s） |
| 心跳周期 | 30s |

### 3.3 NB-IoT（可选）

| 项目 | 说明 |
|------|------|
| 频段 | B1/B3/B5/B8（移动/联通/电信全网通） |
| 协议栈 | CoAP over NB-IoT |
| 上报周期 | 1h ~ 24h（默认 6h，受功耗约束） |
| 电池续航 | 3 年（@6h 上报周期，19000mAh 锂亚电池） |

## 4. 安装方式

| 安装方式 | 说明 | 配套件 |
|---------|------|--------|
| 壁挂安装 | 标准 86mm 暗盒安装 | 螺丝 × 2、膨胀管 × 2 |
| 导轨安装 | 35mm DIN 导轨 | 导轨卡扣（可选） |
| 管道安装 | 配磁吸底座吸附于金属表面 | 磁吸底座（可选） |
| 探头延伸 | 探头加长至 1m/2m/5m | 延长探头套件 |

**安装注意事项**：
1. 避免安装在直接日晒、热源辐射、强磁场附近
2. 室外安装时建议加装防辐射罩（型号 SL-ACC-SHIELD-A）
3. 探头应避免长期浸水，IP67 防护不等于永久浸没
4. RS485 总线最多挂接 32 台设备，总线长度不超过 1200m

## 8. 应用场景说明

### 场景一：新能源电池车间温湿度在线监测

**客户痛点**：锂电池生产车间对温湿度敏感（温度 20±2°C，湿度 30±5%RH），现有仪表无法联网，需要人工巡检，存在记录滞后、异常发现不及时的问题。

**部署方案**：
- SL-T100 壁挂安装于车间关键点位（每 50m² 一台）
- 通过 RS485 总线接入 SL-GW500 工业网关
- 网关上云至客户 MES 系统
- 配合 SL-CT800 控制器实现空调机组联动

**实施效果**：异常响应时长从平均 2 小时缩短至 5 分钟，年度不合格品率下降 18%。

### 场景二：冷链仓储温控追溯

**客户痛点**：医药冷链仓（2-8°C）需要 7×24 温度记录并满足 GSP 合规要求，传统温度记录仪数据导出繁琐。

**部署方案**：
- SL-T100（NB-IoT 版本）部署于每个冷库
- 6 小时上报一次，异常实时告警
- 数据云端存储 5 年，可生成合规报表

**实施效果**：合规审计准备时间从 3 天缩短至 1 小时。

### 场景三：智慧园区环境质量监测

**客户痛点**：园区办公区、机房、停车场需要分项监测环境质量，传统方案成本高、施工复杂。

**部署方案**：
- SL-T100 + SL-GW510 小型网关组合
- Wi-Fi 接入园区局域网，免布线
- 数据接入园区 IBMS 系统

**实施效果**：部署成本较传统方案降低 40%，部署周期从 4 周缩短至 1 周。
