## 3. 通信协议说明

### 3.1 Modbus RTU

| 项目 | 说明 |
|------|------|
| 物理层 | RS485，半双工 |
| 波特率 | 2400 / 4800 / 9600 / 19200 bps（默认 9600） |
| 站地址 | 1-247（默认 1） |
| 寄存器 | CO 浓度：40001（UINT16，1ppm/LSB）<br>CH4 浓度：40002（UINT16，1%LEL/LSB）<br>H2S 浓度：40003（UINT16，0.1ppm/LSB）<br>O2 浓度：40004（UINT16，0.1%VOL/LSB）<br>报警状态：40005（BIT0=CO/BIT1=CH4/BIT2=H2S/BIT3=O2）<br>传感器状态：40006 |

### 3.2 继电器输出

| 通道 | 默认阈值 | 触发动作 |
|------|---------|---------|
| 继电器 1（低报） | CO 25ppm / CH4 20%LEL / H2S 10ppm / O2 19.5% | 触点闭合，输出报警 |
| 继电器 2（高报） | CO 50ppm / CH4 50%LEL / H2S 20ppm / O2 18% | 触点闭合，输出报警+联动排风 |

### 3.3 4-20mA

每路气体独立输出一路 4-20mA，对应 0-满量程。

## 4. 安装方式

| 安装方式 | 适用场景 | 注意事项 |
|---------|---------|---------|
| 壁挂安装 | 控制室、值班室 | 检测比重大的气体（如 H2S）安装低位，检测比重小的气体（如 CH4）安装高位 |
| 抱管安装 | 现场管道 | 配抱箍固定 |
| 流通式安装 | 管道内气体采样 | 配采样泵（选配） |

**安装注意事项**：
1. 检测点应靠近潜在泄漏源，距离 ≤ 2m
2. 避免安装在振动强、风直吹、水淋位置
3. 防爆场合必须配套本安栅使用
4. 传感器每 6 个月建议用标气校准一次

## 8. 应用场景说明

### 场景一：化工园区气体泄漏监测

**客户痛点**：化工园区涉及多种危化品，泄漏监测点位分散，传统固定式仪表布线复杂、维护成本高。

**部署方案**：
- SL-G300 配置 CO/H2S 双气体，壁挂于罐区周边
- RS485 总线接入 SL-GW500 工业网关
- 网关 4G 上云至园区安全监管平台
- 配合 SL-CT800 控制器联动喷淋与排风

**实施效果**：泄漏告警响应时间从 5 分钟缩短至 30 秒，通过应急管理部门验收。

### 场景二：油气储运安全监测

**客户痛点**：油库、加油站需要 7×24 监测可燃气体浓度，传统仪表无远程告警功能。

**部署方案**：
- SL-G300 配置 CH4 单气体，本安型防爆版本
- 4-20mA 接入现有 PLC，无继电器联动排风扇
- 太阳能供电解决偏远站点取电难题

**实施效果**：实现无人值守，年度运维成本下降 45%。

### 场景三：受限空间作业气体检测

**客户痛点**：地下管廊、储罐内部作业前需检测气体浓度，传统便携式设备无法记录数据。

**部署方案**：
- SL-G300 临时安装于作业入口
- 4G 上云，实时传输数据至安全管理平台
- 内置声光报警，超阈值立即停止作业

**实施效果**：作业审批效率提升 60%，零事故达成。
