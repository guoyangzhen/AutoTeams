## 3. 通信协议说明

### 3.1 下行协议

| 协议 | 接口 | 用途 |
|------|------|------|
| Modbus RTU | RS485 | 传感器、仪表数据采集 |
| Modbus TCP | 以太网 | 设备数据采集 |
| OPC UA | 以太网 | 高端设备对接 |
| CANopen | CAN | 运动控制设备 |
| IEC 104 | 以太网 | 电力系统 |

### 3.2 上行协议

| 协议 | 说明 |
|------|------|
| MQTT | 主推，对接云平台 |
| OPC UA | 上行作为 Client |
| Modbus TCP | 上行作为从站 |
| 数据库 | MySQL/InfluxDB 直写 |

### 3.3 本地控制能力

- **本地规则引擎**：256 条规则，基于采集数据实时触发 DO/AO 输出，控制周期 1ms
- **本地逻辑控制**：支持梯形图（LD）、结构化文本（ST）编程（IEC 61131-3）
- **边缘 AI 推理**：基于 TensorFlow Lite/ONNX 模型，本地推理，无需上云
- **断网续航**：本地存储 7 天数据，断网后规则引擎继续运行，恢复网络后断点续传

| 安装方式 | 说明 |
|---------|------|
| DIN 导轨安装 | 标准 35mm DIN 导轨，含 IO 模块 |
| 壁挂安装 | 配壁挂支架（选配） |
| 机柜安装 | 19 英寸机柜面板（选配） |

**安装注意事项**：
1. 控制柜内建议预留 200mm 上下散热空间
2. 继电器输出接感性负载时需加装灭弧电路
3. AI 通道接入热电偶时需配置冷端补偿
4. CAN 总线末端需加装 120Ω 终端电阻

## 8. 应用场景说明

### 场景一：智慧工厂产线联动控制

**客户痛点**：产线设备来自不同厂商，协议各异，缺少统一联动控制层，导致产线启停依赖人工协调。

**部署方案**：
- SL-CT800 通过 Modbus RTU/TCP 采集产线 20+ 设备状态
- 本地规则引擎实现设备启停联动
- 边缘 AI 推理实现产品缺陷检测

**实施效果**：产线启停时间从 15 分钟缩短至 30 秒，良品率提升 3%。

### 场景二：园区能耗优化闭环控制

**客户痛点**：园区空调、照明能耗高，缺少基于实时数据的自动调节。

**部署方案**：
- SL-CT800 接入 SL-T100/SL-P200 采集环境数据
- 通过 Modbus 控制空调主机、新风机组
- 基于人流、温度、能耗多变量 PID 闭环调节

**实施效果**：空调能耗下降 18%，年节省电费 120 万元。

### 场景三：冷链温控自动调节

**客户痛点**：冷库温控依赖人工调节冷机启停，温度波动大，能耗高。

**部署方案**：
- SL-CT800 接入冷库 SL-T100 + 冷机 PLC（Modbus）
- 本地 PID 算法控制冷机变频器
- 边缘 AI 学习冷库热负荷模式，预测性调节

**实施效果**：温度波动从 ±1.5°C 收敛至 ±0.4°C，冷机能耗下降 22%。
