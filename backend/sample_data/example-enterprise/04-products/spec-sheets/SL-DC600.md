## 3. 通信协议说明

### 3.1 下行协议

| 协议 | 接口 | 用途 |
|------|------|------|
| Modbus RTU | RS485 | 传感器、仪表数据采集 |
| 模拟量直采 | AI 通道 | 4-20mA/0-10V 信号直接采集 |
| 热电偶/热电阻 | AI 通道 | T/K/J 型热电偶，PT100/PT1000 |
| 脉冲信号 | HSC | 流量计、电能表脉冲 |

### 3.2 上行协议

| 协议 | 说明 |
|------|------|
| MQTT | 主推，断点续传 |
| HTTP/HTTPS | RESTful POST |
| 数据库 | InfluxDB/MySQL 直写 |
| 文件 | 本地 CSV/Parquet 文件，U 盘导出 |

## 4. 安装方式

| 安装方式 | 说明 |
|---------|------|
| DIN 导轨安装 | 标准 35mm DIN 导轨 |
| 壁挂安装 | 配壁挂支架 |
| 桌面安装 | 自带橡胶脚垫 |

**安装注意事项**：
1. 触摸屏为电容屏，避免戴厚手套操作
2. AI 通道接入热电偶时需配置冷端补偿
3. 4-20mA 信号需配套 250Ω 采样电阻（已内置）
4. 高速脉冲通道接入编码器时需配套差分转单端模块（选配）

## 8. 应用场景说明

### 场景一：生产线设备状态采集

**客户痛点**：注塑机、CNC 等设备状态分散，无统一数据归集，无法做 OEE 分析。

**部署方案**：
- SL-DC600 通过 AI 通道采集设备电流/电压信号
- 通过 DI 通道采集设备运行/停机状态
- 本地存储 30 天数据，4G 上云至 MES 系统

**实施效果**：OEE 数据自动采集，设备利用率提升 12%。

### 场景二：能耗分项计量

**客户痛点**：园区能耗只有总表数据，无法分项计量到产线/楼层/区域。

**部署方案**：
- SL-DC600 通过 RS485 接入多块智能电表
- 通过 HSC 通道采集脉冲电能表
- 本地分时段统计 + 上云

**实施效果**：分项计量精度 99%，能耗分析报告周期从 7 天缩短至 1 天。

### 场景三：实验室数据采集

**客户痛点**：科研实验室多通道传感器数据需长期记录，传统数据采集卡需 PC 全程开机。

**部署方案**：
- SL-DC600 部署于实验室，16 通道同步采集
- 本地 32GB 存储可记录 6 个月数据
- 触摸屏实时查看波形，U 盘一键导出

**实施效果**：PC 不再需常开，数据记录连续性 100%，导出效率提升 80%。
