## 1. 客服流程概述

智链物联客服流程分为 **4 个阶段**：咨询接收 → 问题分级 → 分级处理 → 关闭与回访。

```
咨询接收 → 问题分级 → 分级处理 → 关闭与回访
              │
              ├── L1 常见问题 → 自动处理（FAQ）
              ├── L2 技术问题 → 转技术支持
              └── L3 投诉/升级 → 转客服主管
```

| 阶段 | 主要执行人 | 关键动作 | 时效要求 |
|------|----------|---------|---------|
| 咨询接收 | 客服专员 / 自动系统 | 接收咨询、创建工单 | 即时接收 |
| 问题分级 | 客服专员 / 自动系统 | 按问题类型分级（L1/L2/L3） | 接收后 5 分钟内分级 |
| 分级处理 | 自动系统 / 客服专员 / 技术支持 / 客服主管 | 按 L1/L2/L3 分级处理 | L1 即时 / L2 两小时内 / L3 一小时内 |
| 关闭与回访 | 客服专员 | 关闭工单、满意度回访 | 关闭后 3 个工作日内回访 |

### V2.0 相对 V1.0 的主要改进

| 改进项 | V1.0 | V2.0 |
|--------|------|------|
| 问题分级 | 无分级 | L1 常见问题 / L2 技术问题 / L3 投诉升级 |
| 自动处理边界 | 无定义 | L1 问题（FAQ 覆盖的）自动处理 |
| 升级流程 | 不清晰 | L2 转技术支持，L3 转客服主管，附响应时效 |
| 响应时效 | 未定义 | L1 即时 / L2 两小时内 / L3 一小时内 |

## 2. 咨询接收

### 步骤 2.1 多渠道接收

| 项目 | 内容 |
|------|------|
| 步骤编号 | 2.1 |
| 执行人 | 客服专员 / 自动系统 |
| 操作描述 | 客户咨询通过 5 个渠道接入：400 电话、企业微信、邮件、官网在线客服、客户自助门户；自动系统统一汇聚到工单系统 |
| 输入 | 客户咨询内容（含客户身份、咨询渠道、问题摘要） |
| 输出 | 工单草案 |
| 时效要求 | 电话：3 声内接听；企业微信/在线客服：**即时** 接收；邮件：**1 小时内** 确认收到 |

### 步骤 2.2 客户身份识别

| 项目 | 内容 |
|------|------|
| 步骤编号 | 2.2 |
| 执行人 | 客服专员 / 自动系统 |
| 操作描述 | 通过客户名称/联系人/设备编号识别客户身份，调出客户档案、设备台账、历史工单 |
| 输入 | 客户身份信息 |
| 输出 | 客户上下文信息 |
| 时效要求 | 接收咨询后 **5 分钟内** 完成身份识别 |

### 步骤 2.3 工单创建

| 项目 | 内容 |
|------|------|
| 步骤编号 | 2.3 |
| 执行人 | 客服专员 / 自动系统 |
| 操作描述 | 创建标准工单，必填字段：客户编号、联系人、咨询渠道、问题分类、问题描述、紧急程度 |
| 输入 | 咨询内容、客户上下文 |
| 输出 | 正式工单 |
| 时效要求 | 接收咨询后 **15 分钟内** 创建工单 |

## 3. 问题分级（核心改进）

### 步骤 3.1 自动分级

| 项目 | 内容 |
|------|------|
| 步骤编号 | 3.1 |
| 执行人 | 自动系统 |
| 操作描述 | 自动系统基于关键词匹配和问题分类，对工单进行初步分级；无法自动判断的转客服专员人工分级 |
| 输入 | 工单 |
| 输出 | 分级结果（L1/L2/L3） |
| 时效要求 | 工单创建后 **5 分钟内** 完成分级 |

**问题分级标准**：

| 级别 | 定义 | 典型问题 | 处理方式 |
|------|------|---------|---------|
| L1 常见问题 | FAQ 覆盖的常见咨询 | 产品参数查询、质保期查询、固件升级方法、设备配置说明 | 自动处理 |
| L2 技术问题 | 需要技术判断的工单 | 设备无法连接、数据异常、传感器故障排查、协议对接 | 转技术支持 |
| L3 投诉/升级 | 客户投诉、紧急故障、VIP 客户问题 | 设备批量故障、客户投诉、SLA 违约、S/A 级客户问题 | 转客服主管 |

### 步骤 3.2 人工复核

| 项目 | 内容 |
|------|------|
| 步骤编号 | 3.2 |
| 执行人 | 客服专员 |
| 操作描述 | 客服专员复核自动分级结果，对分级不准的工单进行调整 |
| 输入 | 自动分级结果 |
| 输出 | 最终分级 |
| 时效要求 | 自动分级后 **15 分钟内** 完成复核 |

## 4. 分级处理

### 步骤 4.1 L1 常见问题 — 自动处理（核心改进）

| 项目 | 内容 |
|------|------|
| 步骤编号 | 4.1 |
| 执行人 | 自动系统 |
| 操作描述 | 自动系统从 FAQ 知识库匹配标准答案，直接回复客户；客户确认问题解决后自动关闭工单；客户不满意则升级为 L2 |
| 输入 | L1 工单 |
| 输出 | 自动回复、工单关闭 |
| 时效要求 | **即时** 响应（工单创建后 1 分钟内） |

**自动处理边界**：
- ✅ FAQ 覆盖的问题（产品参数、质保期、固件升级方法、配置说明等）
- ✅ 简单信息查询（订单状态、交付进度、发票进度等）
- ❌ 需要技术判断的问题（设备故障排查、协议对接）
- ❌ 涉及客户投诉、情绪激动的问题
- ❌ S/A 级客户的问题（直接人工处理）

### 步骤 4.2 L2 技术问题 — 转技术支持

| 项目 | 内容 |
|------|------|
| 步骤编号 | 4.2 |
| 执行人 | 客服专员 → 技术支持工程师 / 售前技术支持 |
| 操作描述 | 客服专员将 L2 工单转交技术支持工程师（吴俊豪 SL-2021-048）或售前技术支持（赵明阳 SL-2020-032），附客户上下文和初步排查结果 |
| 输入 | L2 工单 |
| 输出 | 技术支持工单 |
| 时效要求 | 客服专员转交 **30 分钟内** 完成；技术支持 **2 小时内** 响应客户 |

**L2 处理流程**：
```
客服专员（创建工单 + 初步排查）
    ↓
技术支持工程师（2小时内响应，远程协助）
    ↓ 若需现场处理
售后服务专员（24小时内上门）
    ↓ 若涉及产品缺陷
产品部 + 研发部（启动缺陷分析）
```

### 步骤 4.3 L3 投诉/升级 — 转客服主管

| 项目 | 内容 |
|------|------|
| 步骤编号 | 4.3 |
| 执行人 | 客服专员 → 客服主管 |
| 操作描述 | 客服专员将 L3 工单立即转交客服主管（郑晓琳 SL-2019-020），附客户上下文、投诉内容、紧急程度；客服主管评估后决定处理方式（亲自处理/跨部门协调/上报 CEO） |
| 输入 | L3 工单 |
| 输出 | 升级处理记录 |
| 时效要求 | 客服专员转交 **15 分钟内** 完成；客服主管 **1 小时内** 响应客户 |

**L3 处理流程**：
```
客服专员（识别 L3 + 立即转交）
    ↓
客服主管（1小时内响应，评估处理方式）
    ├── 亲自处理（普通投诉）
    ├── 跨部门协调（涉及多部门）
    └── 上报 CEO（重大投诉/战略客户）
```

### 步骤 4.4 处理过程记录

| 项目 | 内容 |
|------|------|
| 步骤编号 | 4.4 |
| 执行人 | 处理人（客服专员/技术支持/客服主管） |
| 操作描述 | 处理人在工单中实时记录处理过程、关键决策、客户反馈 |
| 输入 | 处理过程信息 |
| 输出 | 工单处理记录 |
| 时效要求 | 关键节点 **1 小时内** 更新工单 |

## 5. 工单关闭与回访

### 步骤 5.1 问题解决确认

| 项目 | 内容 |
|------|------|
| 步骤编号 | 5.1 |
| 执行人 | 客服专员 |
| 操作描述 | 客服专员与客户确认问题已解决，邀请客户评价（1-5 分） |
| 输入 | 处理结果 |
| 输出 | 客户确认、满意度评分 |
| 时效要求 | 问题解决后 **1 小时内** 联系客户确认 |

### 步骤 5.2 工单关闭

| 项目 | 内容 |
|------|------|
| 步骤编号 | 5.2 |
| 执行人 | 客服专员 |
| 操作描述 | 客户确认解决后，客服专员关闭工单，填写关闭原因、解决方案、知识沉淀（是否补充 FAQ） |
| 输入 | 客户确认 |
| 输出 | 关闭的工单、知识沉淀 |
| 时效要求 | 客户确认后 **1 个工作日内** 关闭工单 |

### 步骤 5.3 满意度回访

| 项目 | 内容 |
|------|------|
| 步骤编号 | 5.3 |
| 执行人 | 客服专员 |
| 操作描述 | 工单关闭后，客服专员对 L2/L3 工单进行满意度回访；评分 ≤3 分的工单由客服主管二次跟进 |
| 输入 | 关闭的工单 |
| 输出 | 回访记录 |
| 时效要求 | 工单关闭后 **3 个工作日内** 完成回访 |

### 步骤 5.4 FAQ 沉淀

| 项目 | 内容 |
|------|------|
| 步骤编号 | 5.4 |
| 执行人 | 客服专员 |
| 操作描述 | 对 L2 工单中出现的共性问题，客服专员补充到 FAQ 知识库，提升 L1 自动处理覆盖率 |
| 输入 | L2 工单处理记录 |
| 输出 | FAQ 新增/更新 |
| 时效要求 | 每月汇总一次，月末后 **3 个工作日内** 完成 FAQ 更新 |
