## 1. 设备连接与配置类（L1）

### FAQ-C001：设备无法连接网关怎么办？

| 字段 | 内容 |
|------|------|
| 问题 | 设备无法连接网关怎么办？ |
| 标准回答 | 请按以下步骤排查：① 检查设备供电是否正常（电源指示灯是否亮起，SL-T100 需要 DC 5-30V）；② 检查 RS485 接线是否正确（A 接 A、B 接 B，反接会导致无法通信）；③ 检查设备站地址是否与网关配置一致（默认地址 1，可在 1-247 范围设置）；④ 检查波特率是否一致（默认 9600）；⑤ 用万用表测量 RS485 总线 A-B 间电压，应在 0.2-5V 之间；⑥ 单台设备测试，排除总线冲突。若以上步骤无法解决，请提交 L2 技术工单，附设备型号、出厂编号、现场接线照片。 |
| 关联产品 | SL-T100、SL-P200、SL-G300、SL-GW500、SL-GW510 |
| 处理级别 | L1（FAQ 自助）/ L2（排查失败升级） |

| 关联产品 | SL-GW500、SL-GW510、SL-DC600 |
| 处理级别 | L1 |

### FAQ-C003：如何配置 SL-T100 的 MQTT 上报参数？

| 字段 | 内容 |
|------|------|
| 问题 | 如何配置 SL-T100 的 MQTT 上报参数？ |
| 标准回答 | SL-T100 MQTT 版本配置方式：① 通过 SL-ConfigTool 配置工具（推荐）：连接设备 → 选择"MQTT 配置" → 填写 Broker 地址、端口（1883 或 8883）、用户名、密码、主题前缀、上报周期（5s-24h，默认 60s）、QoS（0/1/2，默认 1）；② 通过 Modbus 寄存器配置：寄存器 41001-41020 为 MQTT 配置区，详细地址见用户手册附录 B。主题结构为 `smartlink/{device_id}/{channel}`，数据格式为 JSON：`{"ts":1719600000,"temp":25.6,"humi":58.3,"dewp":16.5,"status":0}`。配置完成后设备自动重启生效。 |
| 关联产品 | SL-T100 |
| 处理级别 | L1 |

### FAQ-C004：如何修改设备的 Modbus 站地址？

| 关联产品 | SL-T100、SL-P200、SL-G300 |

## 2. 数据与异常类（L1/L2）

### FAQ-C005：传感器数据异常如何排查？

| 字段 | 内容 |
|------|------|
| 问题 | 传感器数据异常如何排查？ |
| 标准回答 | 数据异常排查步骤：① 数据恒定不变：检查传感器是否处于死机状态，断电重启；检查 RS485 通信是否中断；② 数据明显偏离实际：检查传感器探头是否被遮挡/污染，清洁探头；检查是否超出量程（如 SL-T100 测温 -40~125°C，超出则数据异常）；③ 数据跳变：检查供电电压是否稳定（DC 5-30V）；检查 RS485 总线是否过长（>1200m 需加中继）；④ 温湿度数据偏差大：执行重新校准（联系客服获取校准流程），或返厂校准。若排查后仍异常，请提交 L2 工单，附设备型号、出厂编号、异常数据截图、正常数据对比。 |
| 关联产品 | SL-T100、SL-P200、SL-G300 |
| 处理级别 | L1（初步排查）/ L2（需深度排查） |

### FAQ-C006：传感器读数精度变差了怎么办？

| 字段 | 内容 |
|------|------|
| 问题 | 传感器读数精度变差了怎么办？ |
| 标准回答 | 精度下降可能原因与处理：① 长期使用漂移：SL-T100 长期稳定性 < 0.1°C/年、< 0.5%RH/年，超过 2 年建议返厂重新校准；② 探头污染：清洁探头（用无水乙醇擦拭，避免刮伤），SL-T100 探头为 316L 不锈钢，SL-G300 气体传感器探头不可自行清洁；③ 环境因素：检查是否新增热源/磁场干扰，调整安装位置；④ 供电异常：检查供电电压是否在范围内，纹波是否过大；⑤ 接口松动：检查 RS485 接线端子是否松动。建议每年送检一次，校准费用 200 元/台，校准周期 5 个工作日。 |
| 关联产品 | SL-T100、SL-P200、SL-G300 |
| 处理级别 | L1 |

### FAQ-C007：SL-G300 气体传感器读数一直为 0 怎么办？

| 字段 | 内容 |
|------|------|
| 问题 | SL-G300 气体传感器读数一直为 0 怎么办？ |
| 标准回答 | 读数为 0 的排查：① 确认现场确实存在目标气体（用便携式检测仪交叉验证）；② 检查传感器模组是否到位（断电后重新插拔传感器模组）；③ 检查传感器模组是否过期（电化学传感器寿命 2 年，催化燃烧 3 年，过期需更换，模组价格 800-1500 元）；④ 检查量程设置是否正确（默认 CO 0-1000ppm，CH4 0-100%LEL）；⑤ 检查标定是否丢失（用标气重新标定，标定套件 SL-ACC-CAL-KIT 1200 元）。若传感器模组已过期，请提交 L2 工单申请更换模组。 |
| 关联产品 | SL-G300 |
| 处理级别 | L1（初步排查）/ L2（需更换模组） |

### FAQ-C008：网关离线了怎么办？

| 字段 | 内容 |
|------|------|
| 问题 | 网关离线了怎么办？ |
| 标准回答 | 网关离线排查：① 检查供电：网关电源指示灯是否亮起，SL-GW500 需 DC 9-36V，SL-GW510 需 DC 7-36V；② 检查网络：以太网版本检查网线是否插好、网口指示灯是否闪烁；4G 版本检查 SIM 卡是否欠费、天线是否连接、信号强度（触摸屏 → 信号）；③ 检查云平台连接：登录云平台查看设备最后上线时间，检查 Broker 地址/端口是否变更；④ 重启网关：断电 30 秒后重新上电；⑤ 查看日志：通过触摸屏 → 系统 → 日志，查看错误信息；⑥ 网络 APN 检查：4G 版本确认 APN 配置正确（移动 cmnet、联通 3gnet、电信 ctnet）。若以上步骤无法恢复，请提交 L2 工单。 |
| 关联产品 | SL-GW500、SL-GW510 |
| 处理级别 | L1 |
