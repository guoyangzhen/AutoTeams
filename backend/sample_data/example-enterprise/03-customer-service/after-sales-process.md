## 1. 售后工单创建流程

### 1.1 工单来源

| 来源 | 接收人 | 时效 |
|------|--------|------|
| 400 售后专线 400-888-7547 | 客服专员 | 3 声内接听 |
| 企业微信客服 | 客服专员 / 自动系统 | 即时 |
| 邮件 support@smartlink-iot.com | 客服专员 | 1 小时内确认 |
| 销售转交 | 客服专员 | 2 小时内建单 |
| 云平台自动告警 | 自动系统 → 客服专员 | 自动建单，5 分钟内人工确认 |

### 1.2 工单创建步骤

| 步骤 | 执行人 | 操作 | 输出 |
|------|--------|------|------|
| 1. 客户身份核验 | 客服专员 | 核验客户名称、联系人、设备出厂编号 | 客户上下文 |
| 2. 故障信息收集 | 客服专员 | 记录故障现象、发生时间、影响范围、现场照片/视频 | 故障描述 |
| 3. 工单分级 | 客服专员 / 自动系统 | 按客服 SOP V2 分级（L1/L2/L3） | 工单级别 |
| 4. 工单派发 | 客服专员 | L1 自动处理；L2 派技术支持；L3 派客服主管 | 派发记录 |
| 5. 客户告知 | 客服专员 | 告知客户工单编号、处理人、预计响应时间 | 通知记录 |

## 2. 上门服务流程

### 2.1 上门服务触发条件

| 条件 | 说明 |
|------|------|
| L2 远程无法解决 | 技术支持远程协助 2 小时仍无法解决 |
| L3 紧急故障 | 设备批量故障、影响生产 |
| 客户要求 | S/A 级客户主动要求上门 |
| 定期巡检 | 年度维保协议约定的巡检 |

### 2.2 上门服务流程

| 步骤 | 执行人 | 操作 | 时效 |
|------|--------|------|------|
| 1. 上门申请 | 客服专员 / 技术支持 | 创建上门服务工单，注明地址、联系人、故障描述 | 远程无法解决后 30 分钟内 |
| 2. 派单 | 客服主管 | 派单给售后服务专员（徐建华 SL-2020-038） | 1 小时内 |
| 3. 预约 | 售后服务专员 | 联系客户确认上门时间 | 派单后 2 小时内 |
| 4. 上门准备 | 售后服务专员 | 准备工具、备件、检测设备 | 上门前 1 天 |
| 5. 现场服务 | 售后服务专员 | 故障诊断、维修/更换、测试验证 | 按预约时间到达 |
| 6. 服务确认 | 售后服务专员 + 客户 | 客户签署《上门服务单》 | 服务完成当场 |
| 7. 工单回填 | 售后服务专员 | 回填维修记录、更换备件清单、客户反馈 | 服务后 1 个工作日内 |

### 2.3 上门响应时效

| 区域 | 响应时效 | 说明 |
|------|---------|------|
| 深圳/广州/东莞 | 24 小时内 | 总部所在地 |
| 上海/北京/成都 | 48 小时内 | 区域服务中心 |
| 其他城市 | 72 小时内 | 需差旅安排 |
| S 级客户 | 优先 +50% | 全国 24 小时内 |

## 3. 维修更换流程

### 3.1 返厂维修流程

| 步骤 | 执行人 | 操作 | 时效 |
|------|--------|------|------|
| 1. RMA 申请 | 客服专员 | 客户提交返厂申请，客服生成 RMA 编号 | 远程无法解决后 2 小时内 |
| 2. 客户寄回 | 客户 | 客户将设备寄回，注明 RMA 编号 | RMA 生成后 7 个工作日内 |
| 3. 到货登记 | 售后服务专员 | 登记到货，分配维修工程师 | 到货当日 |
| 4. 故障诊断 | 维修工程师 | 诊断故障根因，出具检测报告 | 到货后 2 个工作日内 |
| 5. 维修报价 | 财务部 | 质保内免费；质保外出具维修报价 | 诊断后 1 个工作日内 |
| 6. 客户确认 | 客服专员 | 客户确认维修报价 | 报价后 3 个工作日内 |
| 7. 维修执行 | 维修工程师 | 执行维修/更换 | 客户确认后 3-5 个工作日内 |
| 8. 质检 | 质检员（孙丽华） | 维修后质检，出具校准证书 | 维修后 1 个工作日 |
| 9. 返运 | 售后服务专员 | 寄回客户 | 质检通过后 1 个工作日 |

### 3.2 备件更换规则

| 备件类型 | 质保期内 | 质保期外 |
|---------|---------|---------|
| 传感器模组（SL-G300） | 免费（1 年质保） | 800-1500 元/个 |
| 探头组件（SL-T100/P200） | 免费 | 200-300 元 |
| 电池（NB-IoT 版本） | 不在质保范围 | 280 元 |
| 主板/控制板 | 免费 | 设备价格 30-50% |
| 整机更换 | 无法修复时免费换新 | 建议购新机 |

## 4. 保修政策

### 4.1 保修范围

| 项目 | 内容 |
|------|------|
| 标准质保期 | 2 年（自验收之日起算） |
| 延保服务 | 可延保至 5 年，费用为设备价格 8%/年 |
| 气体传感器模组 | 单独质保 1 年（易耗品） |
| 电池 | 不在质保范围（易耗品） |

### 4.2 保修覆盖

| 覆盖 | 不覆盖 |
|------|--------|
| 设备本体硬件故障 | 人为损坏（跌落、进水、错误接线） |
| 性能缺陷（精度漂移） | 不可抗力（雷击、火灾、洪水） |
| 固件 Bug | 非授权人员拆改 |
| 出厂工艺缺陷 | 易耗品（电池、传感器模组） |
| 正常使用下的元器件老化 | 客户未按规格书要求使用 |

### 4.3 保修期内的服务承诺

| 服务 | 承诺 |
|------|------|
| 响应时效 | L1 即时 / L2 两小时 / L3 一小时 |
| 远程支持 | 7×24 小时 |
| 上门服务 | 重点区域 24 小时内 |
| 返厂维修 | 5-7 个工作日 |
| 备件供应 | 质保期内免费 |
| 整机更换 | 无法修复时免费换新 |

### 4.4 维保协议（年度）

S/A 级客户建议签订年度维保协议：

| 项目 | 内容 |
|------|------|
| 费用 | 设备总价 8%/年 |
| 包含 | 不限次维修 + 4 次上门巡检 + 标定校准 + 备件 9 折 |
| 响应 | 优先响应（时效减半） |
| 报告 | 年度设备健康度报告 |
| 延保 | 自动延长至维保期结束 |
