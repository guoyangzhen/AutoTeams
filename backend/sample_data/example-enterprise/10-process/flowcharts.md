## 2. 询盘响应与产品参数查询流程

```
客户询盘
    │
    ▼
销售代表接收（4h内首次响应）
    │
    ├── 能直接回答 ──→ 回复客户 ──→ 进入报价
    │
    └── 需技术支持
            │
            ▼
        创建技术支持请求（CRM）
            │
            ▼
        售前技术支持（赵明阳，2h内响应）
            │
            ├── 能解决 ──→ 回复销售 ──→ 销售回复客户（4h内）──→ 进入报价
            │
            └── 需升级
                    │
                    ▼
                产品经理（周雨桐，4h内响应）
                    │
                    ├── 能解决 ──→ 回复售前 ──→ 回复销售 ──→ 回复客户
                    │
                    └── 需升级
                            │
                            ▼
                        技术支持工程师 + 研发工程师（8h内响应）
                            │
                            ▼
                        回复产品经理 ──→ 回复售前 ──→ 回复销售 ──→ 回复客户
```

## 3. 报价审批流程（V2 优化后）

```
销售代表制作报价单
        │
        ▼
  财务经理审核（1工作日）
        │
        ├── 驳回 ──→ 退回销售修改 ──→ 重新提交
        │
        └── 通过
                │
                ▼
        按金额分级审批
                │
                ├── < 5万 ──→ 销售经理审批（1工作日）
                │                   │
                │                   ├── 驳回 ──→ 退回修改
                │                   └── 通过 ──→ 发送客户
                │
                ├── 5-20万 ──→ 销售总监审批（2工作日）
                │                     │
                │                     ├── 驳回 ──→ 退回修改
                │                     └── 通过 ──→ 发送客户
                │
                └── > 20万 ──→ CEO审批（3工作日）
                                      │
                                      ├── 驳回 ──→ 退回修改
                                      └── 通过 ──→ 发送客户
```

## 4. 客服问题分级处理流程

```
客户咨询
    │
    ▼
接收 + 创建工单（15min内）
    │
    ▼
问题分级（5min内）
    │
    ├── L1 常见问题
    │       │
    │       ▼
    │   自动系统匹配FAQ ──→ 自动回复客户（即时）
    │       │
    │       ├── 客户满意 ──→ 关闭工单
    │       └── 客户不满意 ──→ 升级为 L2
    │
    ├── L2 技术问题
    │       │
    │       ▼
    │   转技术支持（2h内响应）
    │       │
    │       ├── 远程解决 ──→ 客户确认 ──→ 关闭
    │       ├── 需上门 ──→ 售后服务专员（24h内上门）──→ 关闭
    │       └── 涉及产品缺陷 ──→ 转产品部+研发部 ──→ 关闭
    │
    └── L3 投诉/升级
            │
            ▼
        转客服主管（1h内响应）
            │
            ├── 普通投诉 ──→ 主管亲自处理 ──→ 关闭
            ├── 跨部门 ──→ 主管协调多部门 ──→ 关闭
            └── 重大投诉 ──→ 上报CEO ──→ 关闭
```

## 5. 售后服务全流程

```
设备故障
    │
    ▼
客户报修（400/企微/邮件）
    │
    ▼
客服创建工单 + 分级
    │
    ├── L1 ──→ FAQ自动处理 ──→ 解决 ──→ 关闭
    │
    ├── L2 ──→ 技术支持远程协助（2h内）
    │               │
    │               ├── 远程解决 ──→ 关闭
    │               └── 需上门/返厂
    │                       │
    │                       ▼
    │                   ┌─────────┐
    │                   │ 上门服务 │ ──→ 现场修复 ──→ 关闭
    │                   └─────────┘
    │                   ┌─────────┐
    │                   │ 返厂维修 │ ──→ RMA ──→ 诊断 ──→ 维修 ──→ 质检 ──→ 返运 ──→ 关闭
    │                   └─────────┘
    │
    └── L3 ──→ 客服主管处理（1h内）──→ 关闭
```

## 6. 事件驱动协作场景（核心演示流程）

```
收到新询盘（CRM 触发）
    │
    ▼
销售 Agent 接待
    │
    ├── 客户询问产品参数
    │       │
    │       ▼
    │   销售 Agent 无法回答 ──→ 转产品专家 Agent
    │       │                           │
    │       │                           ▼
    │       │                     查阅规格书 + FAQ
    │       │                           │
    │       └───────────────────────────┘
    │       │
    │       ▼
    │   销售 Agent 协助与客户沟通
    │
    ▼
客户同意下订单
    │
    ▼
销售 Agent 创建报价单
    │
    ▼
财务 Agent 审核报价
    │
    ▼
按金额分级审批
    │
    ├── < 5万 ──→ 销售经理 Agent 审批
    ├── 5-20万 ──→ 销售总监 Agent 审批
    └── > 20万 ──→ 老板（CEO）审批
    │
    ▼
审批通过 ──→ 发送报价给客户
    │
    ▼
客户签约 ──→ 合同生效
    │
    ├──→ 客服 Agent 同步订单信息
    │       │
    │       ▼
    │   客服 Agent 通知客户交付计划
    │
    └──→ 生产部 Agent 接收生产工单
            │
            ▼
        生产 + 质检 + 发货
            │
            ▼
        售后 Agent 接管后续服务
```
