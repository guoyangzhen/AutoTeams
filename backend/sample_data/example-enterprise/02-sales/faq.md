## 1. 产品参数类

### FAQ-S001：你们的传感器支持哪些通信协议？

| 字段 | 内容 |
|------|------|
| 问题 | 你们的传感器支持哪些通信协议？ |
| 标准回答 | 智链物联的传感器支持三种通信协议：① Modbus RTU（RS485 接口，工业标准协议，适合有线组网）；② MQTT（以太网/4G 接口，适合云平台直连）；③ NB-IoT（无线广域，适合分散点位免布线）。具体到产品型号：SL-T100 三种协议均支持（按订货型号选择）；SL-P200 支持 Modbus RTU + 4-20mA 模拟量输出；SL-G300 支持 Modbus RTU + 4-20mA + 继电器输出。详细协议参数请查阅对应产品规格书。 |
| 关联产品 | SL-T100、SL-P200、SL-G300 |
| 适用场景 | 售前 |

### FAQ-S005：质保期多长？质保范围包括什么？

| 字段 | 内容 |
|------|------|
| 问题 | 质保期多长？质保范围包括什么？ |
| 标准回答 | 标准质保期为 2 年，可延保至 5 年（延保费为设备价格的 8%/年）。质保范围包括设备本体在正常使用条件下的硬件故障和性能缺陷。质保不包括：① 人为损坏（跌落、进水、错误接线）；② 不可抗力（雷击、火灾）；③ 易耗品（电池、传感器模组，气体传感器模组单独质保 1 年）；④ 非授权人员拆改。质保期内免费维修或更换，质保期外按设备价格的 60% 收费维修。 |
| 关联产品 | 全部产品 |
| 适用场景 | 售前/售后 |

### FAQ-S006：SL-T100 和 SL-P200 的供电方式有什么区别？

| 字段 | 内容 |
|------|------|
| 问题 | SL-T100 和 SL-P200 的供电方式有什么区别？ |
| 标准回答 | SL-T100 供电范围为 DC 5-30V，支持直流供电、锂电池供电（NB-IoT 版本，续航 3 年）、太阳能供电三种方式，功耗 ≤ 50mW。SL-P200 供电范围为 DC 9-36V，支持直流供电和二线制回路供电（24V DC + 4-20mA 回路，模拟量输出版本默认），功耗 ≤ 200mW。SL-P200 不支持电池供电，因为压阻式测量功耗较高。如需无电源场景，建议选择 SL-T100 NB-IoT 版本。 |
| 关联产品 | SL-T100、SL-P200 |
| 适用场景 | 售前 |

## 3. 技术方案类

### FAQ-S011：SL-T100 如何接入客户既有 SCADA 系统？

| 字段 | 内容 |
|------|------|
| 问题 | SL-T100 如何接入客户既有 SCADA 系统？ |
| 标准回答 | SL-T100 接入 SCADA 系统有三种方式：① Modbus RTU 方式：SL-T100 通过 RS485 总线直接接入 SCADA 的 RTU 模块，标准 Modbus 寄存器地址 40001（温度）、40002（湿度）、40003（露点）、40004（状态），波特率默认 9600，站地址 1-247 可配置；② Modbus TCP 方式：通过 SL-GW500 网关转换为 Modbus TCP，SCADA 通过以太网读取；③ OPC UA 方式：通过 SL-GW500 网关转换为 OPC UA，SCADA 作为 OPC UA Client 订阅数据。推荐方案②，兼容性最好。 |
| 关联产品 | SL-T100、SL-GW500 |
| 适用场景 | 售前/售中 |

### FAQ-S012：SL-CT800 智能控制器能否替代 PLC？

| 字段 | 内容 |
|------|------|
| 问题 | SL-CT800 智能控制器能否替代 PLC？ |
| 标准回答 | SL-CT800 在以下场景可替代中小型 PLC：① I/O 规模 ≤ 16DI+8DO+8AI+4AO 的场景；② 控制周期 ≥ 1ms 的场景；③ 不需要复杂运动控制的场景。SL-CT800 优势：① 集成边缘 AI 推理（0.5 TOPS NPU），PLC 不具备；② 支持 TensorFlow Lite/ONNX，可做预测性控制；③ 内置 Linux 系统，支持 Docker 容器化部署；④ 断网续航，本地规则引擎继续运行。不适合替代 PLC 的场景：① I/O 规模 > 48 点；② 需要高速运动控制（伺服/步进）；③ 需要严格 SIL3 及以上功能安全等级。 |
| 关联产品 | SL-CT800 |
| 适用场景 | 售前 |
