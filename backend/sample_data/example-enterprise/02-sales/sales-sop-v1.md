## 1. 销售流程概述

智链物联销售流程分为 **4 个阶段**：线索 → 跟进 → 报价 → 成交。

```
线索 → 跟进 → 报价 → 成交
```

| 阶段 | 主要执行人 | 关键动作 |
|------|----------|---------|
| 线索 | 销售代表 | 接收线索、联系客户 |
| 跟进 | 销售代表 | 了解需求、建立关系 |
| 报价 | 销售代表、销售总监 | 出具报价、审批 |
| 成交 | 销售代表、财务 | 签约、回款 |

## 2. 线索管理

### 步骤 2.1 线索接收

| 项目 | 内容 |
|------|------|
| 步骤编号 | 2.1 |
| 执行人 | 销售代表 |
| 操作描述 | 销售代表从各渠道（官网询盘、展会、转介绍、主动开发）接收客户线索，录入 CRM |
| 输入 | 客户名称、联系人、联系方式、初步需求描述 |
| 输出 | CRM 线索记录 |
| 时效要求 | 无明确规定 |

### 步骤 2.2 线索联系

| 项目 | 内容 |
|------|------|
| 步骤编号 | 2.2 |
| 执行人 | 销售代表 |
| 操作描述 | 销售代表联系客户，了解初步需求 |
| 输入 | CRM 线索记录 |
| 输出 | 跟进记录 |
| 时效要求 | 无明确规定 |

> **痛点**：无明确的线索分配规则（按行业/区域），新线索响应时效无要求，导致部分线索响应滞后，转化率低。

---

## 3. 客户跟进

### 步骤 3.1 需求了解

| 项目 | 内容 |
|------|------|
| 步骤编号 | 3.1 |
| 执行人 | 销售代表 |
| 操作描述 | 销售代表通过电话、邮件、拜访等方式了解客户需求 |
| 输入 | 线索记录 |
| 输出 | 客户需求记录 |
| 时效要求 | 无明确规定 |

### 步骤 3.2 方案沟通

| 项目 | 内容 |
|------|------|
| 步骤编号 | 3.2 |
| 执行人 | 销售代表 |
| 操作描述 | 销售代表基于产品资料向客户介绍方案 |
| 输入 | 客户需求、产品资料 |
| 输出 | 方案建议 |
| 时效要求 | 无明确规定 |

> **痛点**：销售遇到不懂的产品技术参数时，没有标准流程转给产品/售前技术支持，导致响应慢、答错问题，影响客户信任。

### 步骤 3.3 跟进频次

| 项目 | 内容 |
|------|------|
| 步骤编号 | 3.3 |
| 执行人 | 销售代表 |
| 操作描述 | 销售代表按个人习惯跟进客户 |
| 输入 | 客户状态 |
| 输出 | 跟进记录 |
| 时效要求 | 无明确规定 |

> **痛点**：无具体跟进频次要求，依赖销售个人经验，部分客户长期未跟进导致流失。

## 4. 报价流程

### 步骤 4.1 报价单制作

| 项目 | 内容 |
|------|------|
| 步骤编号 | 4.1 |
| 执行人 | 销售代表 |
| 操作描述 | 销售代表根据客户需求制作报价单 |
| 输入 | 客户需求、产品价格表 |
| 输出 | 报价单 |
| 时效要求 | 无明确规定 |

### 步骤 4.2 报价审批

| 项目 | 内容 |
|------|------|
| 步骤编号 | 4.2 |
| 执行人 | 销售总监 |
| 操作描述 | 所有报价统一由销售总监审批 |
| 输入 | 报价单 |
| 输出 | 审批通过/驳回 |
| 时效要求 | 无明确规定 |

> **痛点**：无金额分级审批，所有报价都需总监审批，效率低；总监出差时报价流程阻塞，客户等待时间长。

### 步骤 4.3 报价发送

| 项目 | 内容 |
|------|------|
| 步骤编号 | 4.3 |
| 执行人 | 销售代表 |
| 操作描述 | 审批通过后，销售代表发送报价单给客户 |
| 输入 | 审批通过的报价单 |
| 输出 | 报价单发送记录 |
| 时效要求 | 无明确规定 |

## 7. 丢单处理

| 项目 | 内容 |
|------|------|
| 步骤编号 | 7.1 |
| 执行人 | 销售代表 |
| 操作描述 | 销售代表在 CRM 中将商机状态改为"已丢单" |

| 输出 | CRM 状态更新 |
