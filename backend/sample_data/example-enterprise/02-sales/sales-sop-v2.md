## 1. 销售流程概述

智链物联销售流程分为 **5 个阶段**：线索 → 跟进 → 询盘响应 → 报价 → 成交。

```
线索 → 跟进 → 询盘响应 → 报价 → 成交
                   │
                   └── 产品参数查询（转产品/售前技术支持）
```

| 阶段 | 主要执行人 | 关键动作 | 时效要求 |
|------|----------|---------|---------|
| 线索 | 销售代表 | 接收线索、按规则分配、CRM 录入 | 收到线索 2 小时内响应 |
| 跟进 | 销售代表 | 了解需求、分级跟进、CRM 跟进记录 | 活跃客户 ≥1 次/周 |
| 询盘响应 | 销售代表、售前技术支持 | 询盘响应、产品参数查询、技术问题升级 | 询盘 4 小时内首次响应 |
| 报价 | 销售代表、财务经理、分级审批 | 出具报价、财务审核、分级审批、发送 | 询盘 24 小时内初步报价 |
| 成交 | 销售代表、财务 | 签约、回款、售后转交 | 标准交接信息清单 |

### V2.0 相对 V1.0 的主要改进

| 改进项 | V1.0 | V2.0 |
|--------|------|------|
| 产品参数查询 | 无标准流程 | 新增标准流程，转产品/售前技术支持 |
| 报价审批 | 统一总监审批 | 金额分级审批（<5万经理 / 5-20万总监 / >20万 CEO） |
| 询盘响应时效 | 无要求 | 4 小时首次响应、24 小时初步报价 |
| 线索分配 | 无规则 | 按行业和区域分配，2 小时内响应 |
| 丢单复盘 | 无 | 3 个工作日内复盘，记录原因并改进 |

## 2. 线索管理

### 步骤 2.1 线索接收与分配

| 项目 | 内容 |
|------|------|
| 步骤编号 | 2.1 |
| 执行人 | 销售经理 / 销售代表 |
| 操作描述 | 销售经理接收各渠道线索（官网询盘、展会、转介绍、主动开发），按 **行业 + 区域** 分配规则指派给销售代表；销售代表收到分配后立即联系客户 |
| 输入 | 客户名称、联系人、联系方式、初步需求、来源渠道 |
| 输出 | CRM 线索记录（含分配信息） |
| 时效要求 | 销售经理收到线索后 **1 小时内** 完成分配；销售代表收到分配后 **2 小时内** 首次联系客户 |

**分配规则**：

| 行业 | 区域 | 负责销售 |
|------|------|---------|
| 新能源汽车制造 / 智能制造 | 华东（江浙沪皖） | 陈思远（SL-2021-045） |
| 冷链物流 / 物流仓储 | 华北（京津冀鲁） | 刘梦琪（SL-2022-058） |
| 能源管理 / 智慧园区 | 全国（A/S 级重点客户） | 王浩然（SL-2019-015） |
| 其他 | 按区域就近分配 | 销售经理统筹 |

### 步骤 2.2 线索首次联系

| 项目 | 内容 |
|------|------|
| 步骤编号 | 2.2 |
| 执行人 | 销售代表 |
| 操作描述 | 销售代表通过电话/邮件首次联系客户，确认需求真实性，介绍公司及产品，建立后续沟通节奏 |
| 输入 | CRM 线索记录 |
| 输出 | CRM 跟进记录（含客户需求摘要、下一步行动） |
| 时效要求 | 收到线索分配后 **2 小时内** 完成首次联系；联系后 **1 小时内** 录入 CRM |

## 3. 询盘响应流程（新增）

### 步骤 3.1 询盘首次响应

| 项目 | 内容 |
|------|------|
| 步骤编号 | 3.1 |
| 执行人 | 销售代表 |
| 操作描述 | 收到客户询盘（电话/邮件/微信）后，销售代表立即响应，确认收到询盘并承诺回复时效 |
| 输入 | 客户询盘内容 |
| 输出 | 询盘响应记录 |
| 时效要求 | 工作时间内收到询盘 **4 小时内** 首次响应；非工作时间次日 10:00 前响应 |

### 步骤 3.2 产品参数查询流程（新增，核心改进）

| 项目 | 内容 |
|------|------|
| 步骤编号 | 3.2 |
| 执行人 | 销售代表 → 售前技术支持 / 产品经理 |
| 操作描述 | 销售代表遇到不懂的产品技术参数时，**不得自行猜测或编造**，按以下流程处理：<br>1. 销售代表在 CRM 中创建"技术支持请求"，注明客户问题、涉及产品、回复时效<br>2. 转交售前技术支持（赵明阳 SL-2020-032）<br>3. 售前技术支持查阅产品规格书，2 小时内回复销售代表<br>4. 若问题超出售前技术支持能力，转交产品经理（周雨桐 SL-2020-035）<br>5. 销售代表收到技术回复后，4 小时内回复客户 |
| 输入 | 客户技术问题、涉及产品编号 |
| 输出 | 技术支持请求记录、技术回复 |
| 时效要求 | 售前技术支持 **2 小时内** 响应；产品经理 **4 小时内** 响应；销售代表收到回复后 **4 小时内** 回复客户 |

**技术问题升级路径**：
```
销售代表（创建请求）
    ↓
售前技术支持（2小时内回复，查阅规格书+FAQ）
    ↓ 若无法解决
产品经理（4小时内回复，查阅研发资料）
    ↓ 若仍无法解决
技术支持工程师 + 研发工程师（8小时内回复）
```

### 步骤 3.3 初步报价

| 项目 | 内容 |
|------|------|
| 步骤编号 | 3.3 |
| 执行人 | 销售代表 |
| 操作描述 | 基于客户询盘和产品参数确认，销售代表制作初步报价单 |
| 输入 | 客户需求、产品价格表、技术参数确认结果 |
| 输出 | 初步报价单 |
| 时效要求 | 收到询盘后 **24 小时内** 提供初步报价 |

## 5. 报价流程

### 步骤 5.1 报价单制作

| 项目 | 内容 |
|------|------|
| 步骤编号 | 5.1 |
| 执行人 | 销售代表 |
| 操作描述 | 销售代表根据客户需求制作正式报价单，使用标准报价单模板，包含产品明细、数量、单价、折扣、总价、付款条件、交付周期、质保条款 |
| 输入 | 客户需求、产品价格表、报价单模板 |
| 输出 | 正式报价单 |
| 时效要求 | 客户确认需求后 **2 个工作日内** 出具正式报价单 |

### 步骤 5.2 财务审核

| 项目 | 内容 |
|------|------|
| 步骤编号 | 5.2 |
| 执行人 | 财务经理（何德志 SL-2018-005） |
| 操作描述 | 财务经理审核报价单的价格合规性、折扣合理性、付款条件、税点计算 |
| 输入 | 正式报价单 |
| 输出 | 财务审核通过/修改意见 |
| 时效要求 | 收到报价单后 **1 个工作日内** 完成审核 |

### 步骤 5.3 分级审批（核心改进）

| 项目 | 内容 |
|------|------|
| 步骤编号 | 5.3 |
| 执行人 | 销售经理 / 销售总监 / CEO |
| 操作描述 | 财务审核通过后，按报价金额分级审批 |
| 输入 | 财务审核通过的报价单 |
| 输出 | 审批通过/驳回 |
| 时效要求 | 见下表 |

**金额分级审批规则**：

| 报价金额 | 审批人 | 时效要求 |
|---------|--------|---------|
| < 5 万元 | 销售经理（王浩然 SL-2019-015） | 1 个工作日内 |
| 5-20 万元 | 销售总监（李婉清 SL-2018-002） | 2 个工作日内 |
| > 20 万元 | CEO（张明远 SL-2018-001） | 3 个工作日内 |

> 与 [审批流程图](../09-finance/approval-flow.md) 对应。
