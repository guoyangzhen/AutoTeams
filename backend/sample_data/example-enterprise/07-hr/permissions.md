## 1. 权限模型说明

智链物联采用 **基于角色的权限控制（RBAC）**，权限继承自企业组织结构：

- **数据权限**：定义角色可访问的数据范围（按部门、按所有权、按业务域）
- **操作权限**：定义角色可执行的具体业务操作（创建、编辑、审批、删除）
- **权限继承**：上级自动继承下级的数据可见性，但不继承具体操作权限
- **权限可见性**：每个岗位的权限范围对本人及上级可见，对同级和平级部门不可见

## 3. 操作权限矩阵

### 3.1 报价审批权限（核心场景）

| 角色 | 可创建报价 | 审批额度上限 | 终审权 |
|------|----------|------------|--------|
| 销售代表 | 是 | — | 否 |
| 销售经理 | 是 | 5 万以下 | 是（5 万以下） |
| 销售总监 | 是 | 5-20 万 | 是（5-20 万） |
| CEO | 是 | 20 万以上 | 是（20 万以上） |
| 财务经理 | 否 | — | 财务审核（所有金额） |

**报价审批流程**：
```
销售代表创建报价 → 财务经理审核 → 按金额分级审批 → 发送客户
                                      ├─ <5万：销售经理审批
                                      ├─ 5-20万：销售总监审批
                                      └─ >20万：CEO审批
```

## 4. 敏感数据与特殊规则

### 4.1 敏感数据定义

| 数据类别 | 敏感等级 | 访问限制 |
|---------|---------|---------|
| 客户联系方式（手机/邮箱） | 内部 | 仅客户负责人及上级可见 |
| 客户报价与成交价 | 机密 | 仅销售部相关人员及财务可见 |
| 员工薪资与绩效 | 机密 | 仅人事行政经理、CEO 可见 |
| 产品 BOM 与成本价 | 机密 | 仅产品部、研发部、生产经理可见 |
| 财务凭证与发票 | 机密 | 仅财务部可见 |

### 4.2 特殊规则

1. **数据脱敏**：客服专员查看客户联系方式时，手机号中间 4 位脱敏显示（如 138-****-8001）
2. **审计留痕**：所有查看、编辑、导出操作均记录操作日志，保留 1 年
3. **权限临时授予**：跨部门协作需要时，可由双方部门总监临时授权，有效期默认 7 天
4. **权限回收**：员工离职后 24 小时内回收所有权限，由人事行政部触发，IT 执行
