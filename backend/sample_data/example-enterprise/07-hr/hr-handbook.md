## 1. 入职流程

| 步骤 | 执行人 | 操作 | 时效 |
|------|--------|------|------|
| 1. 录用确认 | 人事行政经理 | 发送录用通知书，确认入职日期 | 面试通过后 2 个工作日内 |
| 2. 入职准备 | 行政专员 | 准备工位、电脑、办公用品、工牌 | 入职前 1 个工作日 |
| 3. 入职登记 | 人事行政经理 | 签订劳动合同、保密协议；收集身份证、学历证、银行卡；录入员工档案 | 入职当日 |
| 4. 系统开通 | 人事行政经理 → IT | 开通企业邮箱、企业微信、CRM 账号，按岗位分配权限（见 [permissions.md](permissions.md)） | 入职当日 |
| 5. 入职培训 | 人事行政经理 + 用人部门 | 公司介绍、规章制度、安全培训、岗位技能培训 | 入职后 1 周内完成 |

---

## 2. 离职流程

| 步骤 | 执行人 | 操作 | 时效 |
|------|--------|------|------|
| 1. 离职申请 | 离职员工 | 提交书面离职申请，抄送直属上级 | 标准提前 30 天 |
| 2. 离职审批 | 直属上级 → 人事行政经理 | 审批离职申请，确认交接计划 | 收到申请后 3 个工作日内 |
| 3. 工作交接 | 离职员工 → 接收人 | 交接客户、项目、文档、设备；填写《工作交接清单》 | 离职前 5 个工作日内完成 |
| 4. 权限回收 | 人事行政经理 → IT | 回收邮箱、企业微信、CRM、系统账号；移交客户数据 | 离职当日 24 小时内 |
| 5. 离职结算 | 财务部 | 结算工资、年假、报销；开具离职证明 | 离职后 5 个工作日内 |

## 3. 考勤规则

### 3.1 工作时间

| 项目 | 内容 |
|------|------|
| 工作制 | 标准工时制，每周 5 天 |
| 工作时间 | 周一至周五 09:00-18:00 |
| 午休时间 | 12:00-13:00 |
| 打卡要求 | 每日上下班各打卡 1 次，支持企业微信定位打卡 |
| 弹性工时 | 销售部、客服部可申请弹性工时（08:30-17:30 或 09:30-18:30） |

### 3.2 请假规则

| 假别 | 说明 | 审批层级 |
|------|------|---------|
| 事假 | 提前 1 天申请，扣除日薪 | 直属上级 |
| 病假 | 当日通知，需提供就医证明，按 80% 发薪 | 直属上级 |
| 年假 | 按工龄累计（5-15 天/年），提前 3 天申请 | 直属上级 → 部门经理 |
| 调休 | 加班可调休，1:1 比例 | 直属上级 |
| 婚假/产假/丧假 | 按国家规定执行 | 部门经理 → 人事行政经理 |

### 3.3 加班规则

| 项目 | 内容 |
|------|------|
| 加班审批 | 需提前填写《加班申请单》，部门经理审批 |
| 加班补偿 | 工作日加班按 1.5 倍计薪，周末加班按 2 倍计薪或调休 |
| 法定节假日 | 按 3 倍计薪 |
| 销售部特殊 | 销售部因客户接待产生的加班，不计加班费，纳入月度绩效 |

## 4. 绩效制度

### 4.1 考核周期

| 岗位类别 | 考核周期 | 详见 |
|---------|---------|------|
| 销售/客服/生产 | 月度 | [KPI 矩阵](../08-kpi/kpi-matrix.md) |
| 产品/研发/售前 | 季度 | [KPI 矩阵](../08-kpi/kpi-matrix.md) |
| 财务/人事/行政 | 半年 | [KPI 矩阵](../08-kpi/kpi-matrix.md) |
| 部门总监/CEO | 年度 | [KPI 矩阵](../08-kpi/kpi-matrix.md) |

### 4.2 绩效等级

| 等级 | 评分区间 | 占比 | 结果 |
|------|---------|------|------|
| S（卓越） | ≥ 95 分 | ≤ 10% | 年终奖 2-3 倍，优先晋升 |
| A（优秀） | 85-94 分 | ≤ 30% | 年终奖 1.5-2 倍 |
| B（达标） | 70-84 分 | ~ 50% | 年终奖 1 倍 |
| C（待改进） | 60-69 分 | ≤ 10% | 年终奖 0.5 倍，需改进计划 |
| D（不合格） | < 60 分 | — | 无年终奖，进入 PIP 或协商离职 |

### 4.3 考核流程

```
员工自评 → 直属上级评分 → 部门经理复核 → 人事行政部校准 → 结果沟通
（每月/季首月 5 日前完成上月/上季考核）
```

### 4.4 晋升机制

| 晋升条件 | 说明 |
|---------|------|
| 连续 2 次 A 及以上 | 可申请晋升 |
| 连续 1 次 S + 1 次 A | 优先晋升 |
| 连续 2 次 C | 触发改进计划 |
| 连续 2 次 D 或 3 次 C | 协商调岗或离职 |

晋升周期：年度晋升（每年 1 月），特殊情况可半年度晋升。
